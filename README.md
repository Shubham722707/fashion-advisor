# Green-Lense: AI-Driven Sustainable Fashion Advisor 🌿

**Green-Lense** is a full-stack AI application designed to help users analyze the environmental impact of their clothing. By combining local vector search with advanced Computer Vision, it provides real-time sustainability metrics for materials and brands.

## 🚀 Features
*   **Tiered AI Search**: Uses `SentenceTransformer` to query a local database of 100,000+ sustainability records[cite: 3].
*   **Visual Search**: Integration with **Gemini 2.0 Flash API** to identify fabrics and brands from uploaded images.
*   **Interactive Dashboard**: A modern, glassmorphism-inspired UI for analyzing fashion sustainability[cite: 2, 3].
*   **Real-time Analytics**: Provides data on water usage, CO2 impact, and biodegradability.

## 🛠️ Tech Stack
*   **Backend**: Flask (Python)
*   **Database**: SQLite (User Auth) & CSV (Sustainability Data)
*   **AI Models**: Google Gemini API & Sentence Transformers
*   **Frontend**: HTML5, CSS3 (Modern Glassmorphism), JavaScript[cite: 3]
